## Blackbridge Grotto accounts

Username format is the **first 4 letters of the last name followed by the first
initial, 1st and 5th characters capitalised** — from the note in the bin in
[[Servants Quarters]].

| Login | Access | Who | Derivation |
|-------|--------|-----|------------|
| MoorR | Admin | [[Randolph Moore]] | Moor + R |
| ThomK | Admin | [[Kimberly Thompson]] | Thom + K |
| BabbA | Personnel Access | [[Anne Babbage]] | Babb + A |
| RuotH | Expired | Mr Ruota | Ruot + H — the bin note reads `RuotF`, deactivated |
| RevaD | Expired | [[Denny Revane]] | Reva + D |

**ThomK is Kimberly Thompson.** Thom(pson) + K(imberly) fits the rule exactly,
the same way the other four do, and she's the only Thom…K name in the notes —
from [[Drafting Strategy Vol 3]].
